# Vector and Queue

## Introduction
This project is a custom implementation of some standard C++ container classes. These containers provide standard methods for element access, container state inspection, modification, and iteration. Is designed for educational purposes within the School 21 program.

## Project Structure
- `src/stl/`: Source files for `vector` and `queue` implementations
- `tests/`: Unit tests using GTest
- `src/Makefile`: Build and test automation

## Features
- C++17 standard
- Templated classes
- Google Test coverage
- Follows STL behavior and Google Style
- lcov (for code coverage analysis)
